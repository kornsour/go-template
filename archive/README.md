# Archive

This folder holds historical and superseded documentation and records from this project — things like retired plans, old design notes, or state that no longer reflects how the project actually works.

Content here is kept for reference and traceability, not for guidance. It describes past decisions, plans, or states of the project, and **must not** be used to understand the current state of the project or to inform new work.

Contributors and coding agents (including AI assistants) should treat everything under this folder as historical context only, never as current truth. If you need to know how the project works today, look at the top-level docs and code instead — anything in `archive/` may be outdated or contradicted by current reality.
